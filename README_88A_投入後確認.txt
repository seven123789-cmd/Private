Phase26N-88A 投入後確認

1. GitHubの main ブランチにZIP内容を投入。
2. Pages反映後、社員詳細を Ctrl+F5。
3. 旧「添付書類」が「社員書類」になっていること。
4. 社員書類 →「書類を追加」で、書類区分に
   ・雇用・契約書類
   ・教育・受講記録
   ・その他
   だけが出ること。
5. 資格・免許 → 任意資格の「書類管理」→「書類を追加」。
   ・登録画面が前面に1枚だけ表示される
   ・区分が「資格証・免許証」固定
   ・キャンセルで元の資格書類管理へ戻る
6. 人事履歴 → 任意履歴の「書類管理」→「書類を追加」。
   ・登録画面が前面に1枚だけ表示される
   ・区分が「辞令・人事通知」「その他人事書類」のみ
   ・キャンセルで元の人事履歴書類管理へ戻る
7. 可能なら1件だけ登録し、登録後に元の書類管理画面へ戻って一覧反映されること。
8. 既存の「開く」「保存」「削除」が動くこと。

問題があれば、番号＋スクショ＋表示されたエラー文をそのまま伝えてください。

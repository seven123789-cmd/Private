# 統合管理システム データ運用基準
基準日: 2026-08-11

## 固定原則
- 社員の外部照合キーは employee_code。氏名は照合キーにしない。
- 資格はID（将来は資格コード）で照合し、名称変更に耐える。
- マスタは原則物理削除せず、無効化して過去データとの参照を維持する。
- 日付は YYYY-MM-DD を標準とする。
- CSVは UTF-8 BOM + CRLF を標準とする。
- 一括更新は「ファイル解析 → 検証 → 差分確認 → DB反映 → 結果記録」の順とする。
- 評価・昇格・資格更新・所属変更は上書きだけで済ませず履歴を保存する。
- DBバックアップと論理エクスポートを併用し、将来別DBへ移行可能な状態を維持する。

## 社員データ取込
現行画面はXLS/XLSXを解析し更新用JSONを作る機能であり、GitHub上のJSONをブラウザから直接更新しない。
また、DB一括反映は一意制約・RLS・監査設計を確認するまで実装しない。
Phase6では必須項目とファイル内社員コード重複の事前検証を追加した。

# ダッシュボード データ契約（Phase4）

2026-08-11 時点。Phase4ではDBスキーマ変更を行わない。

## 参照元
- employees: 登録社員数、所属別人員、昇格候補
- v_employee_license_alerts: 期限切れ・30日以内・90日以内、期限到来予定
- v_license_screen: 所属別の資格登録者数

## 表示上の重要な定義
- 資格保有状況は「資格レコード数」ではなく、所属ごとのユニーク社員数 / 登録社員数。
- 期限状態は APP.normStatus() に統一。
- ダッシュボードから期限アラートへ status クエリを渡し、同じ条件で一覧を開く。
- 「最近の更新」は監査履歴テーブルが存在しないため表示しない。

## 将来追加するデータ基盤
監査・履歴を実装する際は、created_at / created_by / updated_at / updated_by と
履歴テーブルを整備してから「最近の更新」をダッシュボードへ追加する。

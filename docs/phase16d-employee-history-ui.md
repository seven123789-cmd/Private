# Phase16-D 社員詳細：人事異動履歴表示
更新日: 2026-08-11

## 実装
- `employee_detail.html` に「人事異動履歴」カードを追加。
- `assets/js/employee-assignment-history.js` を追加し、DBアクセスを画面コードから分離。
- `employee_assignment_history` と各マスタを参照し、センター・部門・役職/職種・等級を名称表示。
- 現在履歴を明示し、過去履歴は期間と変更区分を表示。
- 既存の社員・資格表示処理は変更せず、追加読込として実装。

## 確認
1. GitHubルートから上書き投入。
2. ログイン後 `employees.html` から任意社員の詳細を開く。
3. 右側に「人事異動履歴」が表示される。
4. 現時点では各社員1件の初期履歴が表示され、「現在」となることを確認。
5. 社員一覧・資格・ログアウトなど既存機能が従来どおり動くことを確認。

Phase26N-86D 投入後の確認手順

1. GitHubへ assets/js/documents.js を上書き投入する。
2. GitHub Pages反映後、社員詳細を Ctrl+F5。
3. 資格・免許 → 「書類管理」を開く。
4. 登録済みPDFで「開く」:
   - 「ファイルを開いています…」が出る
   - PDFが別タブで開く
   - 成功通知が出る
5. 同じPDFで「保存」:
   - 「保存の準備をしています…」が出る
   - ダウンロードが開始される
   - 成功通知が出る
6. 「削除」を押す:
   - 「この操作は元に戻せません」の確認が出る
   - OK後、一覧から消える
   - 「添付書類を削除しました」が出る
7. 削除後、同じ資格の「書類管理」を開き直し「登録済みの証明書はありません」ならOK。
8. 可能なら社員全体の「添付書類」でも、開く/保存/削除が同様に動くことを1件確認。

異常時:
- 何も起きない、ではなく画面右下等にエラー内容が表示されること。
- 表示されたエラー文をそのままChatGPTへ伝える。
